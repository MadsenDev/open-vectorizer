# Ouroboros / dragon logo regression case

This real-world case exposes weaknesses that are largely hidden by the synthetic geometric shootout.

The source is a 1024×1024 ChatGPT-generated ouroboros/dragon logo composed of long smooth tapered curves, repeated scale/feather-like regions, thin highlight linework, and low-contrast black-on-near-black areas.

## Current Open Vectorizer baseline

Using `auto` mode, the observed result is visibly jagged and contains thin stray/spike geometry extending from smooth tapered regions.

- Shapes: **180**
- Nodes: **9,616**
- Primitives: **0 circles, 1 ellipse, 0 rectangles**
- Accuracy: **0.66199**
- SVG size: **229.6 KB**
- Time: **1,835 ms**
- Input: **1024×1024**

## What this case stresses

- smooth Bézier reconstruction rather than dense segment chains
- tapered endpoints and narrow curved regions
- rejection of spurious thin spike/hairline geometry
- stroke/structural recovery
- repeated curved motifs
- low-contrast boundaries
- complexity control on non-primitive artwork

## Expected direction

A successful future result should preserve the flowing character of the source with substantially cleaner geometry. Long curves should be smooth, tapered regions should terminate cleanly, and unsupported spikes should not appear. Node and shape counts should fall substantially without sacrificing raster fidelity simply to obtain prettier numbers.

The goal is not to special-case this artwork. Improvements should generalize to other curved, tapered and line-art logos.

## Provenance

The source image was generated by ChatGPT for the project maintainer and is cleared for inclusion in this project's benchmark/regression corpus.
